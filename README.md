# Infrastructure Lab

Repozytorium zawiera dokumentację testów, konfiguracji
i eksperymentów przeprowadzonych w moim laboratorium IT.

Celem projektów jest praktyczna weryfikacja działania
technologii infrastrukturalnych, mechanizmów wysokiej
dostępności oraz zachowania systemów w sytuacjach awaryjnych.

## Obszary technologiczne

- Linux (Debian, Red Hat)
- Wirtualizacja (Proxmox VE, VMware ESXi)
- Klastry HA i systemy pamięci masowej
- Automatyzacja (Ansible, Terraform)
- Konteneryzacja (Docker)
- Monitoring i bezpieczeństwo
- Sieci komputerowe
